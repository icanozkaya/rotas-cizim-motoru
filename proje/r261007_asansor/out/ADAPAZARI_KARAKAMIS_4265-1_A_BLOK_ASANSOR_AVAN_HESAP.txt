1. ASANSÖR AVAN PROJESİ
1.1. ASANSÖR TRAFİK HESABI
Binada bulunan toplam insan sayısı  B = Σb + n·Σb = 60 + 30%·60 = 78,0 kişi
Ana durak üzerindeki kat adedi  N = 1   Kabin kapasitesi = 10 kişi (800 kg)
P  = %80 doluluk = 0,8 x 10 = 8,0 kişi
H  = Ortalama en yüksek dönüş katı = 1,00
S  = Ortalama durak adedi = 1,00
V  = Kabin hızı = 1,00 m/s     h = Katlar arası mesafe = 4,55 m
tv = h / V = 4,55 s
ts = ta + tk + tg - tv = 2,5 + 3,8 + 7,0 - 4,55 = 8,75 s
tp = Kişi transfer zamanı = 2,2 s
1.1.1. Asansörün Bir Seferi İçin Gerekli Seyir Zamanı
T = 2·H·tv + (S+1)·ts + 2·P·tp = 2 x 1,00 x 4,55 + (1,00 + 1) x 8,75 + 2 x 8,0 x 2,2 = 61,8 s
1.1.1.2. Gerekli Asansör Sayısının Hesabı
R = 5 x 60 x P / T = 300 x 8,0 / 61,8 = 38,83 kişi (5 dakikada bir asansörün taşıdığı)
L = B x k / R = 78,0 x 0,150 / 38,83 = 0,30  ->  1 adet asansör
1.1.1.3. Bekleme Zamanı
I = T / n = 61,8 / 1 = 61,8 s  > 50 s  UYGUN DEĞİL - asansör sayısı/hız/kapasite artırılmalı.
Taşıma kapasitesi yeterli (L = 0,30 ≤ 1); bekleme aralığı sınırı aşılıyor (bkz. kontrol notları).

1.2. ASANSÖR KUVVET HESABI
Gk (kabin kütlesi) = 550 kg   Gy (beyan yükü) = 800 kg   q = 0,5
Karşı ağırlık = Gk + q·Gy = 550 + 0,5 x 800 = 950 kg
Halat: 7 x Ø6,5 mm çelik halat (gh = 0,152 kg/m), 2/1 askı
Halat kütlesi Gh = gh x lh x nh = 0,152 x 19,7 x 7 = 21,0 kg
1.2.1. Kuyu Alt Boşluğu Tabanına Gelen Kuvvetler
P1 (kabin tamponu altı) = 4 x gn x (Gk + Gy) = 4 x 9,81 x (550 + 800) = 52.974 N
P2 (karşı ağırlık tamponu altı) = 4 x gn x Gka = 4 x 9,81 x 950 = 37.278 N
1.2.3. Makine Konsolu Üzerinden Kuyu Perdesine Etki Eden Kuvvetler (duvar konsollu, alttan sehpalı)
F = gn x (Gmakina + Gsehpa + Gmontör + Gk + Gy + Gh + Gka) = 9,81 x (320 + 100 + 150 + 550 + 800 + 21 + 950) = 28.360 N
1.2.4. Asansör Motor Gücü Hesabı
Smaks (artan yük) = Gk + Gh + Gy - Gka = 421 kg   M = Smaks x D/2 = 50,5 kg.m
N = (1/η) x S x V / 102 = (1/0,80) x 421 x 1,00 / 102 = 5,16 kW (6,9 HP)  ->  seçilen 7,5 kW
10 kişilik 1,00 m/s hızında 7,5 kW lık 1 adet insan asansörü tesis edilecektir.
