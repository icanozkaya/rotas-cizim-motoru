1. ASANSÖR AVAN PROJESİ
1.1. ASANSÖR TRAFİK HESABI
Binada bulunan toplam insan sayısı  B = Σb + n·Σb = 102 + 30%·102 = 132,6 kişi
Ana durak üzerindeki kat adedi  N = 4   Kabin kapasitesi = 10 kişi (800 kg)
P  = %80 doluluk = 0,8 x 10 = 8,0 kişi
H  = Ortalama en yüksek dönüş katı = 3,94
S  = Ortalama durak adedi = 3,77
V  = Kabin hızı = 1,00 m/s     h = Katlar arası mesafe = 3,25 m
tv = h / V = 3,25 s
ts = ta + tk + tg - tv = 2,5 + 3,8 + 7,0 - 3,25 = 10,05 s
tp = Kişi transfer zamanı = 2,2 s
1.1.1. Asansörün Bir Seferi İçin Gerekli Seyir Zamanı
T = 2·H·tv + (S+1)·ts + 2·P·tp = 2 x 3,94 x 3,25 + (3,77 + 1) x 10,05 + 2 x 8,0 x 2,2 = 108,8 s
1.1.1.2. Gerekli Asansör Sayısının Hesabı
R = 5 x 60 x P / T = 300 x 8,0 / 108,8 = 22,06 kişi (5 dakikada bir asansörün taşıdığı)
L = B x k / R = 132,6 x 0,075 / 22,06 = 0,45  ->  2 adet asansör
1.1.1.3. Bekleme Zamanı
I = T / n = 108,8 / 2 = 54,4 s  ≤ 100 s  uygundur.
10 kişilik 1,00 m/s hızında 2 adet asansör seçilmesi uygundur.

1.2. ASANSÖR KUVVET HESABI
Gk (kabin kütlesi) = 550 kg   Gy (beyan yükü) = 800 kg   q = 0,5
Karşı ağırlık = Gk + q·Gy = 550 + 0,5 x 800 = 950 kg
Halat kütlesi Gh = gh x lh x nh = 0,373 x 37,9 x 4 = 56,5 kg
1.2.1. Kuyu Alt Boşluğu Tabanına Gelen Kuvvetler
P1 (kabin tamponu altı) = 4 x gn x (Gk + Gy) = 4 x 9,81 x (550 + 800) = 52.974 N
P2 (karşı ağırlık tamponu altı) = 4 x gn x Gka = 4 x 9,81 x 950 = 37.278 N
1.2.3. Kuyu Üstü Betonuna Etki Eden Kuvvetler
F = gn x (Gmakina + Gsehpa + Gmontör + Gk + Gy + Gh + Gka) = 9,81 x (320 + 100 + 150 + 550 + 800 + 57 + 950) = 28.709 N
1.2.4. Asansör Motor Gücü Hesabı
Smaks (artan yük) = Gk + Gh + Gy - Gka = 457 kg   M = Smaks x D/2 = 54,8 kg.m
N = (1/η) x S x V / 102 = (1/0,80) x 457 x 1,00 / 102 = 5,59 kW (7,5 HP)  ->  seçilen 7,5 kW
10 kişilik 1,00 m/s hızında 7,5 kW lık 2 adet insan asansörü tesis edilecektir.
