1. ASANSÖR AVAN PROJESİ
1.1. ASANSÖR TRAFİK HESABI
Binada bulunan toplam insan sayısı  B = Σb + n·Σb = 30 + 30%·30 = 39,0 kişi
Ana durak üzerindeki kat adedi  N = 3   Kabin kapasitesi = 10 kişi (800 kg)
P  = %80 doluluk = 0,8 x 10 = 8,0 kişi
H  = Ortalama en yüksek dönüş katı = 2,98
S  = Ortalama durak adedi = 2,95
V  = Kabin hızı = 1,00 m/s     h = Katlar arası mesafe = 3,17 m
tv = h / V = 3,17 s
ts = ta + tk + tg - tv = 2,5 + 3,8 + 7,0 - 3,17 = 10,13 s
tp = Kişi transfer zamanı = 2,2 s
1.1.1. Asansörün Bir Seferi İçin Gerekli Seyir Zamanı
T = 2·H·tv + (S+1)·ts + 2·P·tp = 2 x 2,98 x 3,17 + (2,95 + 1) x 10,13 + 2 x 8,0 x 2,2 = 94,1 s
1.1.1.2. Gerekli Asansör Sayısının Hesabı
R = 5 x 60 x P / T = 300 x 8,0 / 94,1 = 25,51 kişi (5 dakikada bir asansörün taşıdığı)
L = B x k / R = 39,0 x 0,075 / 25,51 = 0,11  ->  1 adet asansör
1.1.1.3. Bekleme Zamanı
I = T / n = 94,1 / 1 = 94,1 s  ≤ 100 s  uygundur.
10 kişilik 1,00 m/s hızında 1 adet asansör seçilmesi uygundur.

1.2. ASANSÖR KUVVET HESABI
Gk (kabin kütlesi) = 550 kg   Gy (beyan yükü) = 800 kg   q = 0,5
Karşı ağırlık = Gk + q·Gy = 550 + 0,5 x 800 = 950 kg
Halat kütlesi Gh = gh x lh x nh = 0,373 x 19,1 x 4 = 28,5 kg
1.2.1. Kuyu Alt Boşluğu Tabanına Gelen Kuvvetler
P1 (kabin tamponu altı) = 4 x gn x (Gk + Gy) = 4 x 9,81 x (550 + 800) = 52.974 N
P2 (karşı ağırlık tamponu altı) = 4 x gn x Gka = 4 x 9,81 x 950 = 37.278 N
1.2.3. Kuyu Üstü Betonuna Etki Eden Kuvvetler
F = gn x (Gmakina + Gsehpa + Gmontör + Gk + Gy + Gh + Gka) = 9,81 x (320 + 100 + 150 + 550 + 800 + 28 + 950) = 28.434 N
1.2.4. Asansör Motor Gücü Hesabı
Smaks (artan yük) = Gk + Gh + Gy - Gka = 428 kg   M = Smaks x D/2 = 51,4 kg.m
N = (1/η) x S x V / 102 = (1/0,80) x 428 x 1,00 / 102 = 5,25 kW (7,0 HP)  ->  seçilen 7,5 kW
10 kişilik 1,00 m/s hızında 7,5 kW lık 1 adet insan asansörü tesis edilecektir.
